SkateSpots is a full‑stack web application for listing and reviewing skate spots. The app provides complete CRUD for spots and reviews, user authentication and session management, server‑rendered views, file uploads, and utilities for seeding and testing the database. The project is designed with a clear route and model structure and includes server‑side validation to ensure data integrity and maintainability.

Key features
Spot listings with create, read, update, and delete operations

User accounts with authentication and session management

Reviews and ratings for each spot with moderation support

Image uploads for spot galleries and user avatars

Seed scripts and test utilities to populate and validate the database

Server‑rendered views for fast initial load and SEO friendliness

Deployed to Render for easy public access

Technology stack
Backend: Node.js, Express, MongoDB, Mongoose
Frontend: Server‑rendered EJS templates
File uploads: Multer
Deployment: Render
